# Stone Paper Scissors

A fun and interactive Stone Paper Scissors game built using HTML, CSS, and JavaScript. Play against the computer and test your luck and strategy!

## Live Demo

🔗 https://stone-paper-scissors-two-alpha.vercel.app/

## Features

* Play Stone, Paper, Scissors against the computer
* Random computer moves
* Real-time score tracking
* Instant win/lose/draw results
* Responsive and user-friendly interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Sarthak-Misra/stone-paper-scissors.git
```

2. Navigate to the project directory:

```bash
cd stone-paper-scissors
```

3. Open `index.html` in your browser.
